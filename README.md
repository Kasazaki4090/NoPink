# NoPink

> **X (Twitter) 粉红言论采集、语言模型特征分析与 FeedSieve 黑名单词库生成工具链**

NoPink 是一套三段式、隐私优先、支持多机独立同步的 X (Twitter) 降噪工具链：

1. **Step 1 — Chrome 采集插件 (`extension/`)**：在 X 时间线推文头像旁注入一键采集按钮，抓取 `显示名称`、`@ID` 与 `发言正文`，本地存储并支持 **AES-256-GCM 加密打包为每台电脑独立的 `.npdb` 数据库**，安全同步至 OneDrive（文件内无任何明文垃圾内容）。
2. **Step 2 — 本地 AI 关键词提纯 (`analyzer/`)**：加载 OneDrive 目录下的所有 `.npdb` 加密库，解密合并去重后，调用本地大模型（Ollama / LM Studio / llama.cpp）通过两阶段提示词找出高频共现词、剔除日常常见词、保留高区分度核心词。
3. **Step 3 — FeedSieve 黑名单词库生成 (`exporter/`)**：将提纯后的核心词库导出为 [FeedSieve（福滤娃）](https://chromewebstore.google.com/detail/feedsieve/amhdjglnonjaoenddnifpnljgmocfdph) 可用的禁语词表（`.txt` 逐行导入 / YAML 词库包 / JSON 报告）。

## 粉红语言模型 5 大核心类型分析

基于实际采集的 1,307 条典型样本（90 个活跃账号）进行语义聚类，其言论高度套路化，可归纳为以下 **5 种典型说话类型**：

### 1. 贴吧/贴狗式纯粹下三路对线型
* **特征**：极度低幼化、贴吧化、情绪化。放弃一切事实论据，专注于利用无意义的嘲讽词、拟声词、下三路生殖器官谩骂消耗对方精力，追求“精神胜利”。
* **典型话术**：
  * **逗狗体**：“好狗，嘬嘬嘬”、“叫多两声听听”
  * **复读打滚**：“急急急”、“急了”、“破防了”、“招笑”
  * **虚无反弹**：“又在自我介绍了”、“一想到殖人就这智商我就释怀了”
  * **审查威胁**：“打110举报我啊”、“开户/查户籍”

### 2. “大国博弈”宏大叙事与官方口径复读型
* **特征**：沉迷宏大政治叙事、冷战思维与帝国沙文主义，习惯复读官方宣传套话与领袖语录（如“几十年走完欧美几百年”、“集中力量办大事”、“东升西降”、“百年未有之大变局”以及毛/习高频语录）；否定小国或地区的主体性，将日、韩、台、欧洲一概定性为“美国的狗”。
* **典型话术**：
  * **发展奇迹对比体**：“中国几十年走完西方几百年的路”、“弯道超车”、“制度优越性”
  * **父子/仆从叙事**：“美爹”、“日爹”、“认贼作父”、“弱国无外交”
  * **大国霸权论**：“世界只关心三强，谁在乎弹丸小国”、“没有美国牵制你们早成墨西哥了”

### 3. “理中客”诡辩洗地与技术细节抬杠型
* **特征**：不直接骂脏话，而是伪装“客观理性”，通过 **Whataboutism（比烂转移视线）**、和稀泥、或强行编造“技术/物理细节”来为己方洗地、将问题归咎于“恶意剪辑”或“个例”。
* **典型话术**：
  * **比烂转移**：“天下乌鸦一般黑”、“哪国都一样”、“美国也这样”、“美爹那会儿怎么不见你跳”
  * **和稀泥/说教**：“抛开事实不谈”、“一个巴掌拍不响”、“各有各的难处”、“太平洋没加盖”
  * **反咬个例化**：“恶意剪辑”、“断章取义”、“带节奏”、“只看个例”、“幸存者偏差”

### 4. 仇恨历史记忆与种族/国别标签化型
* **特征**：遇事即搬出二战、历史伤痕进行道德与民族仇恨绑架；对周边国家及特定族裔使用高烈度种族蔑称与地域标签。
* **典型话术**：
  * **历史绑架**：“南京大屠杀反省了吗”、“731部队”、“慰安妇”、“靖国神社”
  * **国别/种族蔑称**：“小日本/鬼子/倭国”、“高丽棒子/偷国”、“阿三”、“白皮猪/昂撒”、“黑鬼/尼哥”、“台巴子/绿蛙”

### 5. “成分分析”与意识形态猎巫型
* **特征**：在争论中先审判对方的政治立场与“成分”，把一切对体制、政策或社会现状的批评统一打成“领美金/反华/殖人/行走的五十万”。
* **典型话术**：
  * **扣帽子**：“殖人”、“日杂”、“美狗”、“汉奸”、“公知”、“耗材”、“润人”、“1450”、“50w”、“狗粮”
  * **智力蔑视**：“九年义务教育漏网之鱼”、“翻个墙觉得自己成政治大师了”

### 底层运作机制总结
这批言论本质上是**“认知闭环 + 攻击性防御”**：
1. **前提绝对化**：先预设绝对正义立场，将批评一律定性为“境外势力抹黑/递刀子”。
2. **防御三段跳**：能洗就扣“断章取义/技术原因”；洗不动就启动“Whataboutism 比烂”；进入对线则立刻降级为“嘬嘬嘬/急急急/下三路辱骂”，彻底摧毁正常讨论空间。

## 词库说明 (`dict/block_list.txt`)

根目录下的 [dict/block_list.txt](file:///d:/NoPink/dict/block_list.txt) 按上述分析拆分为 **4 大区块（共 564 条）**，整合了 GitHub 开源词库与本地样本挖掘结果：

1. **`[区块 1]` 骂人类词库（292 条）**：整合 `dablelv/dirty-cnwords`（269 条）、`hua515/zuan`（`zuan.sql` 857 条祖安语录提取）及本地高频对线脏话。
2. **`[区块 2]` 宏大叙事 / 官方口径 + 毛习语录（120 条）**：覆盖发展奇迹对比体、制度优越性套话、甩锅境外势力话术及毛/习高频引用语录。
3. **`[区块 3]` 历史记忆和种族国别标签化（112 条）**：从 `DUT-lujunyu/ToxiCN`（12,011 条）与 `thu-coai/COLDataset`（37,480 条）中挖掘 `race`/`region` 毒性样本并结合本地样本整理。
4. **`[区块 4]` 理中客诡辩 / 洗地话术（40 条）**：高精度 Whataboutism、和稀泥、高位说教与个例化洗地固定句式。

> **NSFW / R18 隔离提示**：`dict/block_list.txt` 为原始全量词库（含部分 NSFW 脏字）。若账号同时用于浏览 NSFW / R18 内容，导入 FeedSieve 前务必剔除单字粗口（如 `操`/`草`/`日`/`干`/`逼`/`骚`）及情趣高频词（如 `主人`/`母狗`/`贱奴`/`高潮`），仅保留政治特异性短语与非情趣人身攻击词。

## 快速开始

### 1. 安装 Chrome 采集插件 (`extension/`)
1. 打开 Chrome 扩展管理页 `chrome://extensions/`，开启右上角 **开发者模式**。
2. 点击 **加载已解压的扩展程序**，选择 `d:\NoPink\extension` 目录。
3. 打开 [x.com](https://x.com)：
   - **单条采集**：每条推文头像下方会出现 `NP` 采集按钮（点击采集单条；**`Shift + 点击`** 可直接将该用户设为目标并提取当前屏 TA 的所有发言）。
   - **单用户整页/自动滚页采集**：打开任意用户主页或 `with_replies` 页面，点击 **「提取本屏」** 或 **「自动滚页提取」** 即可自动向下滚动并过滤无关路人回复。
4. 点击插件图标打开弹窗，设置本机标识（`machineId`）与加密口令（Passphrase），可选择 OneDrive 本地同步目录并一键导出 `nopink-db-<machineId>.npdb`。

### 2. 运行本地 AI 关键词分析 (`analyzer/`)
确保本地已启动 Ollama（如 `ollama serve`）或 LM Studio 等 OpenAI 兼容服务：

```powershell
python -m analyzer.cli `
  --input-dir "$env:OneDrive\NoPink" `
  --output "output/keywords.json" `
  --provider ollama `
  --model qwen2.5:14b
```

### 3. 生成 FeedSieve 黑名单词库 (`exporter/`)

```powershell
python -m exporter.cli `
  --input "output/keywords.json" `
  --out-dir "output/feedsieve" `
  --max-risk low
```

### 4. 运行测试

```powershell
python -m unittest discover -s tests -v
```
