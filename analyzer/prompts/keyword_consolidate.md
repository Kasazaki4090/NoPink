你是一个黑名单词库去噪与精炼专家。
下面提供的是从多个推文批次中初步提取出的候选关键词汇总（包含出现批次数与累计频次）。

你的任务是进行**最终精炼**：
1. **合并同义词/变体**：将意义完全重复或包含关系冗余的词条合并为最核心、命中率最高的表达（例如长短句重叠时保留最精炼的核心词根）。
2. **彻底剔除常见词与高误伤词**：
   - 凡是普通人日常刷推、聊生活、看正常新闻时高频使用的词语，必须从 `core_keywords` 中剔除，并放入 `excluded_common_words`。
   - 宁缺毋滥，只保留真正具有话术辨识度的核心词。
3. **重新校准 `false_positive_risk`**（`low` / `medium` / `high`）。

### 输出格式要求
只输出合法的 JSON 对象，格式如下：
```json
{
  "core_keywords": [
    {
      "term": "核心关键词",
      "score": 95,
      "false_positive_risk": "low",
      "reason": "保留原因"
    }
  ],
  "excluded_common_words": [
    {
      "term": "被剔除的常见词",
      "reason": "剔除原因（如：日常高频词/泛用中性词）"
    }
  ]
}
```
